# NovelMatch V1.0.0

NovelMatch 是一款 AI 个性化小说筛选桌面应用。它从你喜欢和讨厌的小说中学习个人阅读品味，再评估新书与你的匹配度。

## 下载

- Windows 安装包：`NovelMatch_1.0.0_x64-setup.exe`
- 支持系统：Windows 10 / 11

> 当前安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。请确认下载来源后再运行。

## 核心功能

- 多套阅读品味画像：创建、切换、编辑、删除
- 正向参考小说：七维度 1–5 星评分
- 负向参考小说：最差 / 第二差维度选择
- AI 生成个人阅读画像：总结、关键词、喜欢的特征、不喜欢的特征
- 小说链接评估：获取前十章、七维度分析、加权匹配
- 五阶段评估进度，支持取消和失败重试
- 匹配度报告与历史记录
- 用户自配置 OpenAI Chat Completions 兼容模型
- API Key 保存到系统凭据管理器
- 本地 SQLite 持久化，不上传用户画像

## 使用前准备

1. 准备一个 OpenAI Chat Completions 兼容模型服务。
2. 打开软件左侧「模型设置」。
3. 填写 API Key、模型名称、Base URL。
4. 测试连接并保存。
5. 新建画像，导入参考小说并完成评价。
6. 生成画像后，在画像工作台输入小说链接进行评估。

## 支持的小说来源

| 来源 | 状态 |
| --- | --- |
| 番茄小说公开页面 | ✅ 已验证 |
| 其他公开静态页面 | ⚠️ 可能可用 |
| 起点中文网 | ❌ 暂不支持（访问验证） |
| 需要登录 / 付费的页面 | ❌ 不支持 |

本项目不绕过登录、付费墙、验证码或反爬机制。

## 数据与隐私

- 画像、参考小说、评分、评估记录保存在本机 SQLite。
- API Key 保存在 Windows 凭据管理器，不写入数据库或日志。
- 小说正文会发送到你配置的第三方模型服务进行分析。
- 正文只用于当前分析任务，不长期保存完整原文。
- 安装包不包含开发者的画像数据或 API Key。

## 已知限制

- 匹配度是模型驱动的个人偏好估计，不是统计验证过的客观概率。
- 未做大规模真实用户验证。
- 备份/恢复与想读清单持久化尚未实现。
- 不同小说平台的页面结构可能变化，抓取兼容性需要持续维护。
